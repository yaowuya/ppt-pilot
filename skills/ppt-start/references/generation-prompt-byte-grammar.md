# Generation Prompt Byte Grammar

本文件是页面生成 Prompt 字节语法的唯一权威来源；其它引用文件仅链接本文件，不得复制或扩展编译规则。规则正文保留英文以确保逐字稳定。References must require **all rules below** rather than naming a numeric total that can drift.

### Canonical generation-prompt layout, compiler domains, hashes, and preflight

1. **Canonical source.** Every full compile reads `skills/ppt-start/references/generation-prompt-template.md` from the repository. The compiler never reads a `template` member from a payload and never treats a style prompt, style guidance file, registry entry, or caller-supplied complete body as executable prompt bytes. New compilation rejects any `resolved_generation_prompt_template_path` value other than that exact canonical path as `prompt_snapshot_conflict`.
2. **Normalization.** Read UTF-8, reject undecodable bytes, remove one UTF-8 BOM, normalize CRLF and CR to LF, preserve leading blank lines and every non-newline byte, and enforce exactly one terminal LF. `generation_prompt_template_snapshot_id` is SHA-256 over these normalized, pre-substitution canonical template bytes.
3. **Replacement domains.** The normalized canonical template contains exactly one whole-line `[[CANONICAL_NARRATIVE_BULLETS]]` token, exactly one whole-line `[[STYLE_BASELINE]]` token, in that order, and no other `[[...]]` marker of any casing. The legacy `EFFECTIVE_PAGE_SPECIFICATION` token form is invalid for new canonical compilation and must not appear anywhere in the compiled body. Prefixing or suffixing either token makes the template invalid. Replace the first with persisted canonical narrative bullets plus content material from the approved storyboard (role, assertion, audience takeaway, visual intent, content blocks with source ids). The explicit default value is the three bullets headed `金字塔原理`, `精确表达`, and `层级执行`; default prose is never inferred at compile time. Replace the second with the persisted soft style baseline that `StyleBaselineCompiler` projects deterministically from the active style pack's `tokens.json` `prompt_baseline` (palette roles, font stack, spacing rhythm, shape language, composition rules, prohibited motifs). The `tokens.json` read here is the `schema_version: 2` style-pack asset; hand-authored token-string baselines are not a valid replacement source. There is no arbitrary body parameter and no third dynamic replacement marker.
4. **Byte identity.** Replacements are normalized by rule 2 and must end in one LF. Compilation is non-recursive. Apart from the bytes in those two domains, every compiled-body byte is identical to the normalized canonical template. The static segment after the style-baseline token begins with a blank line before the `---` delimiter, so replacement text cannot become a Setext heading. The resulting body must retain canonical `# Role`, `## Workflow`, `### 步骤 1`, `### 步骤 2`, `### 步骤 3`, and `### 兼容约束` headings.
5. **Locked decisions and creative freedom.** Narrative logic is durable and locked: step 1 preserves the approved narrative (role, assertion, audience takeaway, visual intent, SCQA sequence) and the fact floor（事实底线）— exact numbers, units, periods, qualifiers (待确认, 待验收, etc.), causal claims, and source mapping must stay true（不得改变数字、单位、期间、限定词、因果、来源映射）. Within that floor the generator may purify, rephrase, reorder, and supplement content (supplements limited to already-approved research/sources; non-factual transition phrases are free). Step 2 treats the supplied style baseline as soft direction: the generator freely chooses layout, hierarchy, card organization, density, palette usage, and decoration while keeping the whole deck consistent. Step 3 applies the fixed output contract verbatim. The generator does not re-choose narrative logic; it may optimize, rewrite, infer presentation emphasis, choose, and re-choose visual design within the baseline.
6. **SVG contract.** The only response is one fenced XML block containing one complete Office-safe SVG. The canvas is `viewBox="0 0 1280 720"`; all visible content remains inside a 64px safe area; spacing follows a 24px rhythm. Rounded cards use `<path>` plus the SVG `A` arc command, never `rx` or `ry` on `<rect>`. Text uses explicit `<text>` elements and one simple, non-nested `<tspan>` per line. The generated SVG carries no source or citation annotation in its visible text: no footer source line and no source-identifier reference may appear in any visible content. No `foreignObject`, script, remote resource, filter, or active content is allowed.
7. **Envelope.** Persisted bytes are a metadata prefix followed by exactly one separator `b"## Compiled Prompt\n\n"` and then the compiled body. The metadata prefix is `# <slide-id> 页面生成 Prompt`, a blank line, `## Snapshot metadata`, exactly nine metadata fields, and one blank line; it ends immediately before the separator. Metadata fields, in order, are `slide_id`, `storyboard_snapshot_id`, `theme_snapshot_id`, `applied_visual_revision_ids`, `prompt_snapshot_id`, `user_page_request`, `expected_output`, `workspace_output_path`, and `format`. The `format` field value is exactly `creative-brief-v1` for new canonical prompts and distinguishes them from legacy brief-compiled forms. The compiled body begins at byte 0 with `# Role` and ends with exactly one terminal LF. Preflight rejects a fused heading/body, a one-LF or three-LF separator, a repeated separator, a body not beginning `# Role`, and a body with zero or more than one terminal LF. The restriction to the two metadata-prefix headings applies only before the separator; canonical headings inside the body are required, not forbidden.
8. **Paths and dynamic-content preflight.** `workspace_output_path` is exactly `slides/<slide-id>.svg`. Before creating a durable transaction or dispatching a generator, reject either replacement or a supplied body that contains: the old lean S01 form beginning `Role:` and containing `页面 ID:` plus custom `步骤 1/2/3` (or its English equivalent); `PROMPT_SCHEMA_VERSION`, `STYLE_ID`, `HARD_CONSTRAINT_IDS`, or untrusted-wording fence markers from style-owned complete prompts; any unresolved `[[...]]` marker regardless of casing; an injected ATX or Setext Markdown heading; a third replacement marker; a backtick or tilde JSON fence or a raw JSON object/array block; a Unix absolute path whose slash is at line start or follows a non-word/non-CJK boundary such as whitespace, colon, equals, or opening punctuation, Windows drive path, UNC path, protocol-relative URL, or any URI scheme including `ftp:` and `file:`; or instructions such as `Use the Read tool`, `invoke a tool`, read/load/open/fetch/consult an external file, and their Chinese equivalents including `参考外部文件`. General Unix-path detection applies to roots such as `/workspace`, `/Users`, `/data`, and arbitrary `/custom` segments rather than an enumerated root list. Semantic display-copy slashes such as `核心/支撑`, `收入/成本`, and `core/support`, where the slash follows a word or CJK character, are ordinary content and must not be classified as paths. Before creating a durable transaction or dispatching a generator, verify the narrative/material replacement: every number, unit, qualifier, and source id in the material must match the approved storyboard; a mismatch returns the slide to the storyboard owner as `storyboard_fact_mismatch`. Verify the style-baseline replacement is non-empty and derived from a readable `theme.json`; failure returns `style_baseline_unavailable`. Also reject any body that cannot be decomposed byte-exactly into the canonical template's three static segments and the two validated replacement domains.
9. **Body hash.** `compiled_prompt_sha256` is SHA-256 over only the compiled body bytes, starting at body byte 0 `# Role` and including its exactly one terminal LF. It excludes the metadata prefix, the exact `b"## Compiled Prompt\n\n"` separator, and every other envelope byte.
10. **Prompt snapshot payload.** `prompt_snapshot_id` is SHA-256 over canonical JSON bytes with no trailing LF. The payload contains: `applied_visual_revision_ids`, `compiled_prompt_sha256`, `format`, `generation_intent`, `generation_prompt_template_snapshot_id`, `generation_trigger_id`, `outline_snapshot_id`, `resolved_generation_prompt_template_path`, `selected_style_id`, `storyboard_snapshot_id`, `style_baseline_snapshot_id`, `style_kind`, `style_manifest_version`, and `theme_snapshot_id`. `style_baseline_snapshot_id` is SHA-256 over the normalized soft-baseline bytes that `StyleBaselineCompiler` produces deterministically from the active style pack's `tokens.json` `prompt_baseline` (palette roles, font stack, spacing rhythm, shape language, composition rules, prohibited motifs). The resolved template path is exactly `skills/ppt-start/references/generation-prompt-template.md`. Legacy visual-brief snapshot id and effective revision projection hash names, along with `style_prompt_snapshot_id` and `resolved_redesign_prompt_path`, are invalid for new canonical provenance.
11. Hash-capability fallback: when the host provides no deterministic SHA-256 capability, the orchestrator must not fabricate digests. Persist `generation_prompt_template_snapshot_id` and `compiled_prompt_sha256` as the literal `unhashed`, and persist `prompt_snapshot_id` / `transaction_id` as `unhashed:<token>`, where `<token>` is a run-scoped monotonic identifier (one plus the largest numeric suffix among existing `unhashed:` tokens recorded in this run's `run.json.interaction_history`, for example `gp-s03-3`) matching `[0-9a-z][0-9a-z-]*`; the candidate path then uses `slides/.candidates/<slide-id>-<token>.svg`. Resume verification degrades from digest comparison to re-deriving and comparing the nine metadata fields and payload keys; every other byte, provenance, preflight, operation, normalization, and stale-semantics rule above remains unchanged. Inventing a 64 hex digest without computing it is always a hard integrity violation.
12. **Transaction identity.** `transaction_id == prompt_snapshot_id`, including the `sha256:` prefix. A byte-identical canonical input repeats the same identity. Any change in either dynamic replacement, the style-baseline bytes, template bytes, canonical template path/hash, outline snapshot, operation owner, active revision IDs, or storyboard/theme provenance changes the prompt snapshot. `candidate_path` and other execution-only paths never enter the body or snapshot payload.
13. **Operation matrix.** `initial_generation`, `user_recompose`, and `deterministic_fallback` set `compile_full_prompt: true` and compile the canonical body before dispatch. `local_patch` sets `compile_full_prompt: false`, requires the current SVG, and does not compile a full generation prompt.
14. **Stale and conflict semantics.** Coherent canonical-template drift is ordinary stale and requires recompilation. `prompt_snapshot_conflict` is reserved for internally inconsistent provenance, stored body/hash mismatch, non-unique authoritative snapshots, invalid active-revision projection, conflicting operation owners, or envelope injection. Canonical-template or replacement-shape violations fail preflight as `prompt_preflight_invalid`; `style_baseline_unavailable` is the blocking reason when the style baseline cannot be materialized, alongside `prompt_preflight_invalid`. Malformed canonical template marker structure fails as `prompt_template_invalid`.
