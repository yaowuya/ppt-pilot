# 语义布局目录

## 选择规则

根据内容语义选择布局家族：为了让受众接受本页结论，他们必须看到什么关系？不得机械轮换模板。故事板中的 `visual_intent`、`content_blocks`、`source_ids` 和 `density_budget` 先确定语义边界，再由有效 `visual-briefs/<slide-id>.md` 明确唯一焦点、第一至第三阅读位置、主次编码、卡片数量和连接语义；没有完整 brief 不得把布局目录直接当作页面生成 prompt。

每页必须先能指出一个主对象或主判断，再安排支持关系。主次可以通过面积、字号、明暗或位置编码，但不能让所有区块获得相同视觉权重。连接线只在表达真实顺序、依赖、因果或回退时使用，不能作为填空装饰。

除非重复本身表达连续性（例如两个直接可比案例），相邻页面不得重复同一布局家族。整套演示应改变尺度和密度，同时保持主题令牌一致。
## 编译层网格映射

页面生成 Prompt 的步骤 2 固定枚举六种网格（单一焦点、两栏、三栏、主次结合、顶部英雄式、混合网格）；它们是 Bento 实现层，不是语义上限。八族布局按默认映射进入网格表达：

| 布局家族 | 默认网格 |
|---|---|
| comparison | 两栏或主次结合 |
| timeline/process | 顺序化三栏或混合网格 |
| hierarchy/architecture | 主次结合或混合网格 |
| data/chart | 单一焦点或主次结合 |
| cover/section | 单一焦点 |
| single assertion | 单一焦点 |
| bento summary | 直接对应六种网格 |
| close/action | 主次结合 |

映射无法保留家族语义时，在 brief 的 `exceptions` 记录偏离理由，并由 generation prompt 的 `建议语义:` 携带原始 `layout_family`。

## 封面／章节（`cover/section`）

**适用于：** 开启核心论点，或提示重要叙事转折。

- 一个结论或简洁章节承诺；
- 少量支持背景；
- 强烈的尺度对比和有意留白。

不要把每次转场都做成章节页；大多数页面应承载证据或推理。

## 单一结论（`single assertion`）

**适用于：** 一个决定性结论、有来源的引语或高价值指标。

- 主导结论；
- 一个视觉证明或解释关系；
- 常规密度下不超过两个支持细节。

大数字如果缺少单位、期间、比较基准和来源 ID，就是不完整信息。

## 比较（`comparison`）

**适用于：** 方案、前后变化、权衡、基准或情景比较。

- 共同标准和对齐的行列；
- 除非差异本身就是证据，否则给予各项相同视觉待遇；
- 在比较区域上方明确写出结论。

不得比较口径或时间区间不一致的项目。

## 时间线／流程（`timeline/process`）

**适用于：** 有序阶段、里程碑、因果顺序或运营流程。

- 明确方向与起点／终点；
- 只保留少量有意义的阶段，不能做成装饰链条；
- 仅在相关时标注负责人、产出、持续时间或决策。

如果并行分支占主导，应改用层级／架构布局，不要强行做成线性流程。

## 层级／架构（`hierarchy/architecture`）

**适用于：** 系统、分层、依赖关系、运营模型和组织关系。

- 明确依赖或信息流方向；
- 标注边界与层级；
- 尽量减少交叉连接线；
- 明确突出支持本页结论的关键路径。

不能用没有标签的方框代替结构说明。

## 数据／图表（`data/chart`）

**适用于：** 分布、趋势、构成或定量比较。

- 选择能够真实表达比较关系的最简单图表；
- 说明指标、单位、期间、总体和来源 ID；
- 条件允许时直接标注重要数值；
- 强调与本页结论相关的证据。

不得添加伪精度、3D 效果、装饰性坐标轴或掩盖尺度的图表类型。

## Bento 汇总（`bento summary`）

**适用于：** 对彼此不同但共同支持结论的证据点或影响进行综合。

- 一个统领结论和一个可在 3 秒内识别的焦点对象；
- 两到五张真正表达分组或层级的卡片，不形成等权卡片墙；
- 主卡在面积、字号、明暗或位置上显著强于次卡；使用面积编码时，默认至少为单张次卡的 1.5 倍，采用替代编码时必须在 brief 中解释；
- 主卡只在支持同一命题时嵌套 KPI 或证据子卡，不能把无关细节塞进嵌套层；
- 保持卡片内边距和对齐一致，并通过留白而不是更多边框维持阅读顺序。

Bento 不是收纳无关剩余内容的默认布局。卡片不能共同支持一个结论时，应拆页或删除。所有卡片同尺寸、同字号、同表面色而没有主次时属于流程失败，应重新选择层级编码或 `recompose`。

## 收束／行动（`close/action`）

**适用于：** 决策、建议、下一步、负责人或行动号召。

- 重申结果影响，而不是重复整套演示；
- 让所需行动可观察、可执行；
- 只有已知时才写负责人和时间；
- 保留会实质影响决策的风险或条件。

需要决策时，避免只用“谢谢”作为结束信息。

## 密度处理

遵守故事板的密度预算。高密度页面通过分组、对齐和跨页渐进叙事暴露层级。内容无法在最低字号和间距要求内放下时，应拆页或删除低优先级材料；绝不能把关键信息、来源或标签缩小到设计契约下限以下。
