# 嘉为产品风格（jiawei-product）

> 产品经理视角的蓝色科技风格，用于企业解决方案、产品能力与演示汇报。风格令牌是软参考方向；在保持整套风格一致的前提下，由已批准叙事决定布局、层级、卡片组织、信息密度与装饰。

## 角色与文字

- Role 保持为 `产品经理& SVG 可视化编码专家`。生成阶段严格沿用已批准叙事；可以提纯、改写、重排与展开素材，不增加新的事实性主张，不改变数字、单位、期间、限定词或因果关系。
- 字体优先思源黑体，其次微软雅黑：`Source Han Sans / Microsoft YaHei / sans-serif`。
- 字号基线为主标题 40px、分区标题／模块标签／正文 20px、辅助说明 14px；标题字重 700、分区标题 600、标签 500、正文 400。
- 标题位于左上，不加英文翻译，右上角不放 logo 或图标；不强制黑蓝错位方块或固定标题装饰。

## 色彩角色

- 品牌蓝 `#0B74E5` 用于标题或关键强调。
- 深蓝 `#0A5CC9` 用于层级边界或深色强调。
- 亮蓝 `#27B3FF` 用于少量关键点或选中状态。
- 浅蓝 `#EAF5FF` 用于卡片底或弱强调区。
- 墨色 `#111827` 用于页面标题或正文。
- 不要求每页用齐色板；全页至多一个主强调焦点，不使用大量高饱和蓝色块状元素。

## 构图与节奏

- 以非对称模块化 `asymmetric_modular` 为构图方向，按实际内容安排主次，不强制旧版的产品／对比／流程／财务配方或行动模块。
- 卡片间距参考 20px，标准间距节奏 24px，行高 1.4，`page_padding=12` 为软间距参考。所有可见内容仍须位于 64px 页面安全区内，软间距不覆盖这一硬约束。
- 按钮／模块／卡片圆角参考 8／14／16px，描边 1px，连接线 2px。圆角卡片仅用 `path` 与 `A` 绘制，不为 `rect` 设置 `rx` 或 `ry`。
- 禁止背景图片或纹理、毛玻璃、等权卡片墙、强行拆分成数据卡片、“页面结论”四字、标题英文翻译、右上角 logo 或图标，以及穿过文字的连接线。

## 兼容边界与版本

- 使用 1280×720 SVG 画布，正文不小于 20px、辅助说明不小于 14px；文字保持可编辑，使用显式 `text` 与简单非嵌套 `tspan`。仅使用 Office-safe 元素，不依赖滤镜、渐变、图片、远程资源或工具调用。
- 本文件与 `tokens.json` 定义风格身份、令牌和指导，`prompt.md` 从同包令牌确定性合成；它们不是单页成品示例，不得从既有 SVG 反推构图。
- 内置版本 1.2.0 采用用户更新的软风格基线。已有运行的主题版本、模板快照或视觉批准不自动迁移；采用新版必须走正常视觉修订／确认流程。用户自建包仍遵守发布器的不可变 ID 规则。
