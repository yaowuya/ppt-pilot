# 嘉为产品风格（jiawei-product）

> 面向产品经理视角的商务 + 科技 + 简约风格。蓝色科技风、模块化、流程化、细描边、圆角卡片、信息密度中等。适合产品能力概览、解决方案介绍、平台架构/流程展示与产品路线推进页。

## 使用场景

- 产品能力/平台介绍页：用模块化分区呈现能力蓝图，右栏放卖点说明。
- 解决方案页：左 2/3 架构流程图 + 右 1/3 卖点卡。
- 路线/推进页：横向流程 + 箭头引导，突出"当前重点"与"下一步要做的事"。
- 财务/指标汇报页：表格放在页面上方或左上方，主体空间用于展开重点事项与推进目标。

## 语义表面规则（判断用，具体数值见 `tokens.json.prompt_baseline`）

- 主品牌蓝 `#0B74E5` 用于标题条、主模块条、关键按钮；深品牌蓝 `#0A5CC9` 与亮蓝 `#27B3FF` 用于不同层级的少量强调，不使用渐变。
- 浅蓝底 `#EAF5FF` 用于卡片底/弱强调区/右侧卖点卡；白底为主背景；浅灰 `#F6F9FC` 可选作柔和页面氛围。
- 标题黑/深灰 `#111827` 用于大标题，正文灰 `#4B5563` 用于说明，次要灰 `#6B7280` 用于注释。
- 圆角：按钮 6-10px、大模块条 12-16px、卡片 14-18px；轻投影 `0 4 12 rgba(15,23,42,0.08)`；浅蓝描边 1px，或不描边仅靠底色区分。
- 标题固定左上，左侧黑蓝错位方块装饰（左上黑、右下蓝）；标题无英文翻译；右上角不放 logo/图标。

## 内容驱动构图配方

- **产品能力概览**：顶部标题栏 + 中部主流程/模块区 + 底部平台承载区 + 右侧卖点说明栏。
- **对比**：不对称双栏，主卡显著。**流程/里程碑**：横向流程 + 箭头引导，上方主能力条、中间步骤按钮、下方管理模块矩阵。
- 不要为了 Bento Grid 强行拆分信息；指标完成度优先用简洁表格。页面重点放在"当前重点"与"下一步要做的事"，必要时融入"推进方向"或行动模块中，禁止出现"页面结论"四个字。
- 整体大留白、浅色底、少量蓝色强调与细描边，不使用滤镜阴影，避免大量高饱和蓝色块状元素。

## 禁止母题

人类可读版本；机器可读结构化版本唯一来自 `tokens.json.prompt_baseline.prohibited_motifs`。不得把阶段进行中写成最终验收，不得把相关/假设/提案渲染成已证实因果，不得用颜色替代必要文字。
