# 嘉为产品风格（jiawei-product）

> 产品经理视角的商务 + 科技 + 简约风格，用于企业解决方案、产品能力、平台流程与推进汇报。品牌识别是固定要求，页面结构由已批准内容决定，不为 Bento Grid 强行拆分。

## 固定识别与标题

- Role 为 `产品经理& SVG 可视化编码专家`。文稿提纯与叙事选择在审查层完成；生成阶段可以精简表达，但不改变已批准事实、数字、限定或因果关系。
- 页面标题固定左上；左侧使用黑蓝错位方块，黑色方块位于左上、品牌蓝方块位于右下；标题文字在方块右侧左对齐。
- 主标题采用 36px（原要求 34–38px 范围内）、700 字重、纯黑 `#000000`。标题不加英文翻译，右上角不放 logo、图标或其他装饰。
- 字体优先微软雅黑，其次思源黑体；对应安全字体栈为 `Microsoft YaHei / Source Han Sans / sans-serif`。

## 色彩与表面

- 白色 `#FFFFFF` 为主背景，浅灰 `#F6F9FC` 为可选背景；不要求每页用齐调色板。
- 品牌蓝 `#0B74E5` 用于主模块条、按钮与少量重点，深蓝 `#0A5CC9` 和亮蓝 `#27B3FF` 仅作少量层级或高光强调，不用渐变或大面积高饱和蓝块。
- 浅蓝 `#EAF5FF` 用于卡片/弱强调表面，`#D8EEFF` 用于克制的斜切或梯形底托，`#BFE3FF` 用于浅边框与分割线。
- 正文灰 `#4B5563`、辅助灰 `#6B7280` 与纯黑标题分工明确；细长流程箭头使用浅蓝 `#60A5FA`。
- 大留白、浅色底、少量卡片、弱边框、弱阴影。图标采用小型蓝色单色或蓝灰线性/扁平几何风格。弱阴影不得依赖 SVG 滤镜。

## 按内容应用的构图配方

- **产品能力/平台介绍**：顶部标题栏、中部主流程/模块区、下方平台承载区；可优先左 2/3 架构流程图 + 右 1/3 卖点说明。卖点卡用小图标、粗标题和灰色说明，按内容减少卡片。
- **对比**：对等关系可用 50/50 双栏；有主次时可用 2/3 主 + 1/3 次。核心信息更显著，支撑信息保持次级，不把并列关系伪造成主次。
- **流程/里程碑**：横向流程与从左到右的细箭头；根据实际素材组织主能力条、步骤按钮、管理模块矩阵与平台集成条，不虚构流程或依赖。
- **指标/财务汇报**：指标完成情况优先用一个简洁表格，不拆成多个数据卡片。财务表格位于页面上方或左上方，主体空间展开重点事项、行动计划和推进目标。
- 页面优先突出已批准素材中的“当前重点”和“下一步要做的事情”；总结融入“推进方向”或行动模块，禁止出现“页面结论”四个字。缺少相应素材时不得补造内容。

## 兼容边界与版本

- 1280×720 画布、64px 页面安全区；卡片间距与卡片内边距均取 24px，符合原文间距不少于 20px 的要求。按钮/模块/卡片圆角分别为 8/14/16px，仅用 `path` 和 `A` 绘制；不使用带 `rx`/`ry` 的 rect、渐变、滤镜、图片或远程资源。
- 字号统一为 SVG px：分区标题 26px、标签/正文 20px、注释 14px。正文遵守插件 ≥20px 的硬下限，不直接把原文的 pt 数值当作 px；它不是对原字号的逐字复刻。
- 本文件、`tokens.json` 与其确定性合成的 `prompt.md` 保持一致；品牌、标题、完整配色和条件式配方必须进入传给 generator 的正文，不能只留在本说明中。它们不是单页成品示例，不得从既有 SVG 反推构图。
- 内置版本 1.1.0 恢复原始风格要求。已有运行的主题版本、模板快照或视觉批准不自动迁移；采用新版必须走正常视觉修订/确认流程。用户自建包仍遵守发布器的不可变 ID 规则。
