# 嘉为年中总结风格

## 使用场景

适用于 SaaS、研发、交付、组织和治理类管理汇报。结论先行，优先展示判断、证据边界、过程门槛和管理行动。它不是营销海报或数据大屏风格；页面必须让管理者快速辨认“发生了什么、证据到哪里、下一步决定什么”。

## 核心识别

默认画布为 `#F5F8FC`。单行结论标题允许一个短语使用标题强调蓝 `#1E63FF`，形成短语级重点，但不能把整行标题染成强调色。复杂论证页允许一张 `#10233F` 深色主卡建立唯一焦点；不能让所有页面都复制同一深色主卡，也不能为了品牌识别增加左侧长蓝条。

品牌主蓝 `#156BFF` 用于最高价值结论、行动或选中状态，天空蓝 `#65B7F9` 用于次级关系，紫色 `#8866FD` 用于 AI、有界试点、高风险或失败分支。默认背景不使用图片、纹理或渐变。

## 语义表面

- **白色事实卡**：承载已观察事实、已验证状态、数字和来源可追溯内容；
- **浅蓝表面**：承载证据边界、核心结论或需集中阅读的限定信息；
- **浅紫表面／紫色标记**：承载 AI、有界试点、高风险、失败或回退分支；
- **深色主卡**：只承载本页关键命题、综合判断或需要强聚焦的决策对象。

颜色必须与文字标签同时表达语义，不能仅靠颜色区分事实、假设或风险。相同语义在整套演示中使用相同角色，不把品牌蓝平均分配给所有卡片。

## 层级 Bento

卡片覆盖约 `40%–60%`，其余空间用于阅读节奏和关系分隔。主卡必须在面积、字号、明暗或位置上显著强于次卡；面积编码时，主卡默认至少是单张次卡的 `1.5` 倍。主卡可以嵌套 KPI 子卡形成二级层级，但嵌套只用于同一命题的量化证据。

卡片数量由内容语义决定，不追求填满画布。相邻卡片必须表达分组、比较、因果、顺序或证据层级。每页最多一处轻阴影；其他卡片使用描边、表面色和留白区分，避免全页阴影和漂浮感。

## 字体与标题

使用标题、主命题、区块标题、正文、辅助、微标签六级阶梯：

- 标题优先单行，并且是可判断的结论；
- 主命题承担页面唯一焦点，不能与区块标题同字号同权重；
- 区块标题用于组织论证，不重复主标题；
- 关键决策信息使用正文及以上字号；
- 辅助文字只解释上下文或限定条件；
- 微标签只承载编号、时间点或非关键元信息。

短语级强调不能拆散句义，也不能通过每个词不同颜色制造噪声。字重和字号先建立层级，颜色只做第二编码。

## 内容驱动构图

必须根据内容选择构图，而不是机械重复一个模板：

- 论证页可使用“事实—命题—控制—有界试点”，让证据共同指向可证伪命题；
- 流程页可使用连续闸门和回退分支，连接线只表示真实过程关系；
- 时间箱页可使用角色索引、比例时间轴和结果矩阵，时间长度与阶段含义保持一致；
- 对比页根据比较维度选择不对称双栏、主次矩阵或聚焦差异，而不是等权卡片墙；
- 决策页用一个主决策对象统领证据、风险和行动，不把所有选项渲染为同等推荐。

一套演示可以共享颜色、字体、间距和形状令牌，但每页构图必须响应其论证、流程、时间、比较或决策语义。

## 禁止项

禁止：

- 左侧长蓝条、通用标题轨或没有信息含义的品牌装饰；
- 背景图片、纹理、渐变和远程资源；
- 等权卡片墙、全页阴影或每张卡片都使用相同视觉权重；
- 无语义装饰线、穿过文字的连接线或暗示错误关系的箭头；
- 把阶段完成、阶段交付或进行中写成最终验收；
- 把观察、相关性、假设或提案渲染成已证实因果；
- 用颜色替代必要文字，或把所有文字染成系列／品牌色；
- 为了适配参考图删掉限定语、来源、关键数字或管理行动。

## 完整生成 prompt 与页面语义例外

`REDESIGN.md` 是本风格的完整生成 prompt。STYLE 图层仅表达抽象身份与边界；它不是 rendered exemplar、不是固定布局，也不是可直接复制的页面范本。该风格包不得包含单页成品示例、参考构图或固定区域图；每页结构必须从当前 visual brief 的内容语义重新推导。

当页面语义与风格抽象语法出现冲突时，页面语义优先；任何偏离完整生成 prompt 的布局、密度或表面语义都必须在 `exceptions` 中记录（例如：

- 证据链与页面结构不匹配时的例外构图；
- 强迫的管理动作导致的非典型卡片密度；
- 时间页中的非层级表达路径。

）。
